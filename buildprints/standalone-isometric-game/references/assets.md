# Asset-Maker quality and spending contract

## Preferred stack and real gap
Use **WaveSpeed + (RetroDiffusion OR Media4Agents)**, not three interchangeable alternatives. The essential WaveSpeed capabilities are reference editing with `bytedance/seedream-v5.0-pro/edit` and background removal with `bria/remove-background`. Seedream is the image model; Seedance is not a substitute. Media4Agents selection does not additionally require direct RetroDiffusion access.

At the pinned framework commit, `game-asset-generation` provides provider-neutral preparation, alpha review and provenance, and a WaveSpeed client supporting Seedream text/edit plus `wavespeed-ai/image-background-remover`. Its explicit allowlist does NOT include `bria/remove-background`. Do not pass Bria to that wrapper, rename its existing remover, invent flags/endpoints, or describe it as an equivalent essential capability. No bundled Media4Agents integration was found. Discover an already authorized integration and its current documented schema if those routes are selected; otherwise report the exact missing capability. This packet does not add a provider client.

## Before any paid or external action
1. Read the approved asset technique and supplied/licensed material first. Generation is conditional, not a compulsory account-setup ceremony. Author original game-specific composition/maps even when using rights-cleared reusable art.
2. Inspect available integrations and current official model support, access and price evidence without a billable probe. Distinguish listed, accessible, price-known and successfully used; none implies the others. No provider availability or price was verified during packet authoring. A failed account endpoint alone does not disprove a documented public generation route.
3. Obtain budget approval covering generation, edits, background removal, retries and any chargeable first URL fetch, plus permission to upload the specific references. Preserve already sufficient approvals. Use host-owned masked secret entry; never put credentials, signed private URLs or authorization headers in chat, source or provenance. Browser/runtime code receives only local game assets, never provider secrets.
4. One spend owner reserves conservative upper-bound cost before each call. Keep `.game-quality/generation-ledger.md` from its template when generation is chosen. Unknown charges count against the ceiling until reconciled. Submit once; recover an existing job rather than duplicate it after timeout. Honor Retry-After and stop at the approved budget. No unlimited probes or unapproved paid fallbacks.

## Production route
Read the pinned `game-asset-generation/SKILL.md` and the chosen provider recipe only when needed. Use approved identity crops and reference roles; keep rejected candidates out of later identity inputs. Prepare one representative candidate, preserve raw output, decode actual dimensions and alpha, inspect light/dark backgrounds and fine holes, then bind measured crops/anchors to the actual runtime manifest. A painted checkerboard is not transparency; background removal does not fix perspective.

Use directional authoring for required facings/actions, animated-environments for stable moving layers, tileset authoring for material continuity, and art integration for grounded assemblies. Keep original hashes, exact requests/model/job identity, transformations, license/attribution and final local runtime paths in `templates/asset-provenance.md` records. Never assume a requested atlas grid or filename proves real frame geometry.

## Free-only fallback
Missing preferred access is an explicit **quality limitation**, not silent permission to downgrade. Offer suitable licensed free packs, user-owned art, or approved local/free authoring routes. Verify attribution, modification, redistribution and commercial-use terms for intended delivery; “found online” is not a license. Preserve an explicitly generated-art requirement as blocked unless the user approves a changed technique. Custom SVG is last resort, not equivalent-quality production art. All fallbacks must meet the SAME agreed visual, motion, contact and gameplay acceptance; failed quality stays failed. Continue unrelated authorized codework while access/budget is blocked.
