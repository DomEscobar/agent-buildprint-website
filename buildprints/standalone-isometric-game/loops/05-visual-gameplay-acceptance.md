# Close defects against the complete running candidate

## How to implement this loop
Read the host `AGENTS.md`, `.buildprint/next-agent.md`, approved `PROJECT_CONTRACT.md`, packet `02-identity.md` and `loops/loop-flow.md`. Resolve packet paths relative to immutable snapshots after bootstrap; host data paths are relative to the game root. Load only relevant pinned framework skills under the available tool policy. Run only authorized work, with concise progress updates and durable upstream receipts.

1. Confirm the recorded authorization covers the required game captures, gameplay, reviewer and measurements. Preserve an existing request; if declined or unavailable do not run optional proof or assert acceptance. Follow `references/visual-acceptance.md` and the pinned upstream production/acceptance/comparison guides.
2. Confirm prerequisites through motion are valid, inspect actual full packed-art coverage, then create the v3 candidate snapshot with production receipts. Bind running-bundle identity and loaded source/asset/scene inputs using `templates/capture-receipt.md`; do not trust a commit alone for dirty builds.
3. Capture all protected current views and required clips/interaction evidence in the real host. Inspect loading/crop failures first. Use upstream compare to assemble original target/current/previous evidence; do not manufacture images or crop/stretch away defects. A style reference is not a layout-replica instruction.
4. Give an authorized fresh-context reviewer the contract, targets, actual pixels/playback and complete prior findings, without preferred verdicts. Unavailable independence is declared self-review before freeze; mandatory independence remains blocked. Missing vision/capture never becomes a fictional pass.
5. Apply localized fixes to the actual product, make a new candidate and fresh captures, then compare with previous review. Preserve every finding as resolved/open/regressed. After two repeated failures change strategy using the upstream checkpoint; if the material blocker persists, escalate it with evidence instead of endless retries or weakening requirements.
6. Finish whole-world final review and run upstream accept with the same v3 receipt directory. Require separate visual, motion, gameplay and performance outcomes. Follow `review.md` claim separation and retain failed/unverified/stale states. No mock data, placeholder substitutions, changed target or silent scope cuts.

## Building objective
Establish evidence-backed acceptance of the complete actual game against the unchanged approved target and scope. This loop is explicitly requested future game verification, not a license to run tests or reviewers while authoring the packet. The final candidate must match the loaded code, assets, scene definitions, build configuration and protected reference/contract bytes, including dirty worktree content. Review must see current images, complete motion and normal interaction paths at the declared viewports; passing structural receipts or a carefully staged screenshot cannot supply the verdict. Defects remain actionable open work until repaired and freshly observed, and missing capability or authorization remains unverified.

## DO NOT
Use placeholders, functionless buttons or mocked/sample data as final product or live proof. Do not copy demo/example assets/maps, edit framework internals, invent APIs or commands, spend without approval, weaken protected criteria, fake independent review, or reinterpret calibration as the full deliverable. No tests/benchmarks/browser QA/independent review during packet AUTHORING; this loop describes future authorized game work.

## Minimum proof before moving on
Current complete candidate, valid prerequisite/final receipts, actual inspected full views and watched motion/normal gameplay evidence, independent or openly self-labeled review, repaired prior findings and upstream final acceptance result. If proof is missing, deliver an explicitly unverified/blocked status rather than claim complete-game acceptance.

## Handoff note
Record the actual implemented scope, observed evidence, exact candidate/inputs, open defects and capability/authorization blockers. Link upstream production status/receipts instead of copying their verdicts. Keep current loop/next eligible work in local progress; the immutable packet index is not an auto-advancing scheduler. Preserve approvals, full scope and delegated-work ownership.
