# Contract review and honest completion

This is the FUTURE GAME acceptance step, only under explicit user authorization recorded during alignment. No tests, benchmarks, browser QA or independent review are run to author this packet.

Read `00-goal.md`, the approved `PROJECT_CONTRACT.md`, the active loop contract (Building objective), and `references/visual-acceptance.md`. A fresh-context reviewer receives current frozen inputs, real captures/playback, targets and prior defects, not builder chat or builder rationale. The builder must not score its own work as independent: fabricated independence is REVIEW_INVALID. When no independent reviewer is available, upstream self-review is explicitly labeled; a contractual independent-review requirement remains blocked.

Use the existing upstream comparison and production acceptance records; do not invent another scoring ceremony. Confirm requirement translation covers the whole game, not calibration. Actually inspect each protected visual view and observe motion and normal gameplay journeys. Check rights, cost, privacy, input, loading, save/recovery and all promised states. Do not approve scene data that differs from the loaded runtime or captures tied to another candidate.

Return per requirement: pass/fail/unverified, candidate/evidence, affected viewport/state, actionable defect and repair. Carry every previous finding as resolved/open/regressed. No still-only motion approval, no pass from metadata, no broad tolerance changes or substituted assets that lower the agreed target. Repairs route through fresh candidate captures and re-review; bounded repeated failure escalates without a scope cut.

`loop_core_passed` means the active loop's observable functional outcome is proven. `claim_qualified` additionally requires every applicable full-scope visual, motion, gameplay, performance and review condition on the actual final candidate. Neither a loop pass nor tool success alone qualifies a complete game. Separate implemented / functionally verified / visually accepted; list review independence and missing reach. Local evidence never implies public release proof.
