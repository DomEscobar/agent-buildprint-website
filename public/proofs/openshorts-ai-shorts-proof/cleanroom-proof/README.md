# OpenShorts Clean-room Proof

Runnable proof built from the mapped Buildprint package, not from OpenShorts source code.

## What it proves

A portable AI shorts production pipeline can be rebuilt as deterministic domain logic and a small web UI:

product input → analysis → 5-segment UGC script → actor/voice selection → mocked provider jobs → 9:16 composition plan → gallery SEO/social publishing manifest.

## What it does not prove

- No full OpenShorts clone/parity.
- No provider API parity for Gemini, ElevenLabs, fal.ai, Hailuo, Kling, VEED, Remotion, S3, or Upload-Post.
- No actual video rendering or social publishing.
- No quality claim for generated videos.
